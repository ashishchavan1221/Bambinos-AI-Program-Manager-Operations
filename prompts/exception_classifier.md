# Exception Classification

Classify renewal problems using these reason codes:

- TEACHER_FORM_MISSING
- PAYMENT_NOT_CONFIRMED
- PARTIAL_PAYMENT
- CONTACT_MISMATCH
- DUPLICATE_FORM
- INVOICE_NOT_FOUND
- BATCH_CAPACITY_FULL
- DISCOUNT_POLICY_CHECK
- BATCH_CHANGE_PARENT_SELECTION

For every exception provide:

1. Invoice ID
2. Student ID
3. Exception reason
4. Severity
5. Responsible team
6. Recommended action

Do not make automatic approval decisions.

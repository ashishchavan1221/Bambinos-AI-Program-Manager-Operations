# Reconciliation Results

This folder contains the output generated by the Python reconciliation engine.

## Output Files

1. auto_approved.csv
   Contains records that pass all mandatory validation checks.

2. exceptions.csv
   Contains records requiring manual investigation.

3. message_drafts.csv
   Contains follow-up message drafts for parents, teachers and Operations.

4. reconciliation_audit.csv
   Contains validation decisions and processing details.

All results must be generated using the actual assessment datasets.
